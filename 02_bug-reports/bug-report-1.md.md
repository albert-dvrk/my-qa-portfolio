# Баг-репорт: Создание двух слотов вместо одного

**Название:** При двойном клике на кнопку "Добавить слот" создается два слота вместо одного

**Окружение:**
- ОС: Windows 11
- Браузер: Яндекс Браузер (последняя версия)

**Предусловия:**
- Открыта страница `https://aiqa.su/pomidorqa/profile/slots`
- Пользователь зарегистрирован и авторизован
- База данных пуста (нет созданных слотов)

**Шаги воспроизведения:**
1. Выбрать текущее время (например, 23:11)
2. Выбрать завтрашнюю дату (например, 13 августа 2026 года)
3. Двойным кликом нажать на кнопку "Добавить слот"

**Ожидаемый результат:**
- Создан один слот с выбранными датой и временем

**Фактический результат:**
- Создано два слота с одинаковыми датой и временем

**Приоритет:** Средний (Medium)
**Серьезность:** Major (дублирование данных в базе данных, влияет на бизнес-логику)

**Вложения:**
- Скриншот страницы с двумя созданными слотами
